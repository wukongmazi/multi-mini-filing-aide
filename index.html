SYSTEM · AGENT ACTIVITY

Agent 活动 · 审计时间线

Qoder Cloud Agents 的 Webhook 事件（Agent / Session / Thread 生命周期）实时回传并在此留痕；配合 Qoder Deployment 实现云端定时巡检的闭环可观测。

🛰️部署与回调状态

将下方地址注册到 Qoder（POST /webhook_endpoints，订阅事件如 session.status_idled、agent.created），即可接收真实事件回调。验签密钥使用参数设置中的 QODER_WEBHOOK_SIGNING_SECRET。

🔗Webhook 端点管理

在 Qoder 云端创建 / 管理 Webhook 端点，订阅 Agent 生命周期事件。创建后 Qoder 会主动向你的接收地址推送事件。

签名密钥由 Qoder 在创建后自动生成并返回一次，系统会立即写入「参数设置 → QODER_WEBHOOK_SIGNING_SECRET」用于后续投递验签，无需手动填写。

SYSTEM · 参数设置

参数设置

配置 Qoder Cloud Agents 与三通道通知。优先级：页面设置 > 环境变量（.env）；保存后即时生效并持久化到本地数据库，重启不丢。

🤖Qoder Cloud Agents

此 PAT 同时作为数据隔离标识：在本系统录入/查看的所有数据（小程序登记、巡检历史、事件时间线）都按该 PAT 划分。换一个 PAT（参数设置 > 环境变量）即切换到另一个独立空间，只能看到该 PAT 对应的数据；他人录入自己的 PAT 也同理互不可见。该值仅用于派生隔离，绝不返回给前端。

🔐访问安全

普通成员（访客）无法修改访问密码；只有持有环境变量 MASTER_PASSWORD 的管理员登录后才能改。若未配置 MASTER_PASSWORD，则沿用旧逻辑（任何登录者均可在本页改密码）。
